# Значки каналов

Навигация пространства показывает тип канала одним и тем же значком в категориях и в списке без категории. Название типа доступно через подсказку и `aria-label`.

| Тип | Значок | Подпись |
| --- | --- | --- |
| Текстовый | `Hash` | Текстовый канал |
| `добро-пожаловать` (текстовый) | `BookOpen` | Текстовый канал |
| Голосовой | `Volume2` | Голосовой канал |
| Сцена | `Radio` | Сцена |
| Форум | `MessagesSquare` | Форум |
| Объявления | `Bell` | Объявления |
| Доска | `Columns3` | Доска |

Значок замка допустим только после передачи из API реального ограничения доступа к конкретному каналу. Приватность пространства сама по себе не означает, что канал закрыт для его участников.
